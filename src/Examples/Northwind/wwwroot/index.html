Vista · jQuery DataTables adapter demo

Live grid over the read-only Northwind view vProductCategory, driven end-to-end by the DataTables adapter (POST /api/views/vProductCategory/datatable) and the QueryBuilder schema (GET /api/views/vProductCategory/querybuilder).

Three request channels

Every control below maps to one of Vista's neutral query channels (Decision Log D111).

SearchThe DataTables global search box → Contains over searchable string fields.
FilterThe jQuery-QueryBuilder rules below → the structured jsonQB channel.
ScopeThe category selector → the server-trusted externalFilter channel.

Scope & structured filter

The filter builder is populated from the view's QueryBuilder schema, so only server-allowed fields and operators appear.
