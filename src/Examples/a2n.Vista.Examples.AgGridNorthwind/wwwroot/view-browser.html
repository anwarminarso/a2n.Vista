Vista · View Browser

Pick any registered Northwind view and browse it end-to-end: columns are discovered from GET {route}/metadata, the advanced filter is populated from GET {route}/querybuilder, and every page combines paging, global search, multi-sort, and the structured filter in one POST {route}/datatable request.

View selector & global search

The selector lists only explicitly-registered Vista views (secure-by-default). Global search is applied server-side across the view's searchable string fields once the term reaches the minimum length.

Advanced filter

The builder is populated from the view's QueryBuilder schema, so only server-allowed fields and operators appear. Applied server-side through the neutral structured filter channel.
