# Support

Thanks for using a2n.Vista. This project is in **pre-alpha**, so support is
best-effort and the API may change between commits.

## Getting help

- **Questions & ideas** — open a [GitHub Discussion](https://github.com/anwarminarso/a2n.Vista/discussions)
  (or a question issue if Discussions are not enabled).
- **Bugs** — open a [bug report](https://github.com/anwarminarso/a2n.Vista/issues/new/choose)
  with a minimal reproduction.
- **Feature requests** — open a feature request issue describing the use case.
- **Security issues** — do **not** open a public issue; see [SECURITY](./SECURITY.md).

## Before opening an issue

- Check the [README](./README.md), the [ROADMAP](./ROADMAP.md), and the specs in
  [`docs/spec/`](./docs/spec/).
- Search existing issues to avoid duplicates.
- Include your .NET version, Vista version/commit, and a minimal reproduction.

## Documentation

Specs and design docs live in [`docs/`](./docs/). They describe intended behavior
and may run ahead of the implementation while the project is pre-alpha.
